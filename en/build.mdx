Configure generation during compilation. Alpha.2 uses the complete direct-generator setup in [First query](/en/quickstart). The Gradle/Maven plugins below are implemented for alpha.3 and currently require locally staged artifacts.

## Stage alpha.3

Clone the [source repository](https://github.com/thirtyeighttwentysix/volan) and run from its root:
```bash
./gradlew publishAllPublicationsToReleaseTestRepository "-Pversion=0.1.0-alpha.3" -PvolanUnsignedLocalPublication --no-configuration-cache
```

This creates `build/release-repository`; it does not publish to Central. Use that repository for generator, plugins and runtime together. Keep the local candidate version `0.1.0-alpha.3` distinct from a published release. Main's default version is `0.1.0-alpha.3-SNAPSHOT`.

## Gradle

These are the checked-in [Gradle consumer](https://github.com/thirtyeighttwentysix/volan/tree/main/plugin-smoke/gradle) files. Java 17+, Kotlin/JVM main sources, tested Gradle 9.8.0. `settings.gradle.kts`:
```kotlin
pluginManagement {
    repositories {
        val staged = providers.gradleProperty("volanRepository").orNull
        if (staged != null) maven { url = uri(staged) }
        mavenCentral()
        gradlePluginPortal()
    }
    plugins {
        id("io.github.thirtyeighttwentysix.volan") version providers.gradleProperty("volanVersion").getOrElse("0.1.0-alpha.3")
    }
}

dependencyResolutionManagement {
    repositories {
        val staged = providers.gradleProperty("volanRepository").orNull
        if (staged != null) maven { url = uri(staged) }
        mavenCentral()
    }
}
rootProject.name = "volan-gradle-consumer"
```

`build.gradle.kts`:
```kotlin
plugins {
    kotlin("jvm") version "2.4.20"
    id("io.github.thirtyeighttwentysix.volan")
}

val volanVersion = providers.gradleProperty("volanVersion").getOrElse("0.1.0-alpha.3")
dependencies {
    implementation("io.github.thirtyeighttwentysix:volan-dialect-h2:$volanVersion")
    runtimeOnly("com.h2database:h2:2.5.252")
    testImplementation("org.junit.jupiter:junit-jupiter:6.1.3")
    testImplementation("io.github.thirtyeighttwentysix:volan-coroutines:$volanVersion")
    testImplementation("io.github.thirtyeighttwentysix:volan-micrometer:$volanVersion")
    testRuntimeOnly("org.junit.platform:junit-platform-launcher:6.1.3")
    testRuntimeOnly("org.slf4j:slf4j-nop:2.0.20")
}
kotlin { compilerOptions { jvmTarget.set(org.jetbrains.kotlin.gradle.dsl.JvmTarget.JVM_17) } }
tasks.withType<JavaCompile>().configureEach { options.release.set(17) }
tasks.test { useJUnitPlatform() }
```

Use the H2 schema from [Examples](/en/examples). Run `./gradlew -p plugin-smoke/gradle test "-PvolanRepository=file:///absolute/path/build/release-repository"`. On Windows, a URI is `file:///D:/Projects/Volan/build/release-repository`.

The plugin adds matching runtime, registers generated Kotlin and wires `volanGenerate` into compilation. Add the dialect and driver yourself. Customize paths with `volan { schemaFile.set(layout.projectDirectory.file("db/schema.volan")); outputDirectory.set(layout.buildDirectory.dir("generated/client")) }`.

## Maven

Maven 3.9+, Java 17+. Complete [Maven consumer](https://github.com/thirtyeighttwentysix/volan/tree/main/plugin-smoke/maven) POM:
```xml
<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
  <modelVersion>4.0.0</modelVersion>
  <groupId>example</groupId><artifactId>volan-maven-consumer</artifactId><version>1.0</version>
  <properties>
    <volan.version>0.1.0-alpha.3</volan.version>
    <kotlin.version>2.4.20</kotlin.version>
    <kotlin.compiler.jdkRelease>17</kotlin.compiler.jdkRelease>
    <kotlin.compiler.daemon>false</kotlin.compiler.daemon>
    <kotlin.compiler.incremental>true</kotlin.compiler.incremental>
    <maven.compiler.release>17</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>
  <dependencies>
    <dependency><groupId>io.github.thirtyeighttwentysix</groupId><artifactId>volan-runtime</artifactId><version>${volan.version}</version></dependency>
    <dependency><groupId>io.github.thirtyeighttwentysix</groupId><artifactId>volan-dialect-h2</artifactId><version>${volan.version}</version></dependency>
    <dependency><groupId>com.h2database</groupId><artifactId>h2</artifactId><version>2.5.252</version><scope>runtime</scope></dependency>
    <dependency><groupId>org.junit.jupiter</groupId><artifactId>junit-jupiter</artifactId><version>6.1.3</version><scope>test</scope></dependency>
    <dependency><groupId>org.slf4j</groupId><artifactId>slf4j-nop</artifactId><version>2.0.20</version><scope>test</scope></dependency>
  </dependencies>
  <build>
    <plugins>
      <plugin>
        <groupId>io.github.thirtyeighttwentysix</groupId><artifactId>volan-maven-plugin</artifactId><version>${volan.version}</version>
        <executions><execution><goals><goal>generate</goal></goals></execution></executions>
      </plugin>
      <plugin>
        <groupId>org.jetbrains.kotlin</groupId><artifactId>kotlin-maven-plugin</artifactId><version>${kotlin.version}</version>
        <extensions>true</extensions>
      </plugin>
      <plugin><groupId>org.apache.maven.plugins</groupId><artifactId>maven-compiler-plugin</artifactId><version>3.16.0</version></plugin>
      <plugin><groupId>org.apache.maven.plugins</groupId><artifactId>maven-surefire-plugin</artifactId><version>3.5.4</version></plugin>
    </plugins>
  </build>
  <profiles>
    <profile>
      <id>staged</id><activation><property><name>volanRepository</name></property></activation>
      <repositories><repository><id>volan-staged</id><url>${volanRepository}</url></repository></repositories>
      <pluginRepositories><pluginRepository><id>volan-staged</id><url>${volanRepository}</url></pluginRepository></pluginRepositories>
    </profile>
  </profiles>
</project>
```

Run `mvn -f plugin-smoke/maven/pom.xml test -DvolanRepository=file:///absolute/path/build/release-repository`.

The `generate` goal defaults to `generate-sources`. Generated Kotlin needs the Kotlin compiler even for Java applications. The BOM aligns libraries, not plugin versions. Incremental Kotlin compilation removes bytecode of deleted models; otherwise run `mvn clean test` after schema removals.

Maven defaults: `schema.volan`, `target/generated-sources/volan`. Override with `schemaFile` / `outputDirectory` or `-Dvolan.schemaFile` / `-Dvolan.outputDirectory`.

## Generated output

Output directories are build products owned by generation. Build plugins override the schema's output setting. Do not put application code there or modify the `.volan-generated-files` manifest. Generation removes obsolete owned sources, refuses collisions and links inside output. Compilation never modifies the database.
