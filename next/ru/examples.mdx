<Info>
Volan 1.0.0. Библиотеки и плагины сборки доступны в Maven Central.
</Info>

Четыре независимых проекта используют плагин и библиотеки 1.0.0 из Central. Они применяют сохранённые миграции перед работой клиента. Нужен JDK 17+; для H2 отдельный сервер базы не требуется.

| Проект | Проверки |
| --- | --- |
| [Kotlin](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/kotlin-basic) | Транзакция, запись, чтение и откат |
| [Java](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/java-basic) | Java callbacks, клиент на Kotlin, откат |
| [Spring Boot](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/spring-boot) | Bean клиента, constructor injection, реальный context и закрытие |
| [Ktor](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/ktor) | Запросы через корутины, POST/GET, ответы 400/404 и закрытие |

Из checkout тега `v1.0.0` выполни:

```bash
./gradlew -p examples/kotlin-basic test run
./gradlew -p examples/java-basic test run
./gradlew -p examples/spring-boot test run
./gradlew -p examples/ktor test
```

В PowerShell используй `.\gradlew.bat`. `./gradlew -p examples/ktor run` запускает сервер на `127.0.0.1:8080`; Ctrl+C завершает его. Консольные примеры выводят `Saved and read: Ada`.

## Проверка

Релизный workflow собирает проекты сначала с signed staging, затем с реальными загрузками из Central. `scripts/verify-examples.py --version 1.0.0` выполняет те же проверки Central. `scripts/verify-plugins.py --version 1.0.0` дополнительно проверяет Gradle/Maven, кеши и удаление исходников старых моделей. Скрипты работают с временными копиями.

[Первый запрос](/next/ru/quickstart) разбирает файлы. Подробные фрагменты запросов используют схему User/Post: создай её и соответствующие таблицы перед запуском. Пример H2 не доказывает все гарантии другого провайдера.
