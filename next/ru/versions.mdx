<Info>
Volan 1.0.0. Библиотеки и плагины сборки доступны в Maven Central.
</Info>

Используй плагин сборки, генератор и runtime версии **1.0.0**, затем повтори генерацию. Новый генератор может вызывать методы, которых нет в старом runtime.

| Версия | Библиотеки | CLI |
| --- | --- | --- |
| 1.0.0 | Central: пять провайдеров баз, плагины сборки, корутины и метрики отдельными модулями | GitHub tag `v1.0.0` |
| 0.1.0-alpha.2 | Central: PostgreSQL и SQLite | Нет CLI-архивов |
| 0.1.0-alpha.1 | Central: PostgreSQL | Нет CLI-архивов |

BOM выравнивает версии библиотек. Версии плагинов задаются явно. Обновление глобального CLI не меняет `build.gradle.kts` или `pom.xml`, а установка зависимостей не обновляет CLI. Старый preview `cli-v0.1.0-alpha.3-preview.1` остаётся отдельной поставкой.

## Обновление

Сохрани схему и миграции в Git, обнови зависимости и плагины вместе, повтори генерацию, компиляцию и тесты на целевой базе. Проверяй DDL отдельно. Перекомпилируй код с `DropConstraint.copy`: сигнатура data class изменилась после alpha.2. Собственные задачи генерации можно заменить [плагинами сборки](/next/ru/build).

[Central metadata](https://repo.maven.apache.org/maven2/io/github/thirtyeighttwentysix/volan-runtime/maven-metadata.xml), [1.0.0](https://github.com/thirtyeighttwentysix/volan/releases/tag/v1.0.0).

Этот раздел соответствует неизменяемому тегу исходников `v1.0.0`. Документация alpha остаётся в выборе версий. Локальный unsigned staging проверяет артефакты, но не публикует их в Central.
