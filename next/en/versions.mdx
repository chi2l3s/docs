<Info>
Volan 1.0.0. Libraries and build plugins are available from Maven Central.
</Info>

Keep the build plugin, generator and runtime at **1.0.0**, then regenerate the client. A newer generator can call methods missing from an older runtime.

| Version | Libraries | CLI |
| --- | --- | --- |
| 1.0.0 | Central: five database providers, build plugins, optional coroutines and metrics | GitHub tag `v1.0.0` |
| 0.1.0-alpha.2 | Central: PostgreSQL and SQLite | No CLI archives |
| 0.1.0-alpha.1 | Central: PostgreSQL | No CLI archives |

The BOM aligns library modules. Set plugin versions explicitly. Updating the global CLI does not update `build.gradle.kts` or `pom.xml`. Installing dependencies does not update the CLI. The earlier preview `cli-v0.1.0-alpha.3-preview.1` remains available separately.

## Upgrade

Commit schema and migration changes, update dependencies and plugins together, regenerate, compile and test on the target database. Review DDL separately. Recompile consumers of `DropConstraint.copy`: its data-class signature changed since alpha.2. Custom alpha generation tasks can be replaced with the [build plugins](/next/en/build).

[Central metadata](https://repo.maven.apache.org/maven2/io/github/thirtyeighttwentysix/volan-runtime/maven-metadata.xml), [1.0.0](https://github.com/thirtyeighttwentysix/volan/releases/tag/v1.0.0).

This section targets the immutable `v1.0.0` source tag. Alpha documentation remains in the version selector. Local unsigned staging verifies artifacts; it does not publish them to Central.
