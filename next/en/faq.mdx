These questions often come up between installation and the first real endpoint. Each answer explains ORM behavior and points to a worked example or a more detailed guide.

## Do I need the CLI first?

An application needs libraries, a dialect and a JDBC driver. The CLI is useful for schema work but optional in [First query](/next/en/quickstart), which invokes generation from the build. `volan init` creates `schema.volan`; configure the Gradle or Maven application separately.

## Why does the schema exist but the table does not?

The schema describes models and generated APIs. Generation never connects to a database, so it cannot create the table. Apply DDL or a [migration](/next/en/migrations) to the same JDBC URL the client uses. For SQLite, also check the working directory: a relative path can open another file.

## Why does a Java application need a Kotlin plugin?

The client is generated as Kotlin and must compile before Java uses it. `javaFriendly = true` enables getters, setters and callbacks. Your application code remains Java; the Kotlin compiler handles generated sources. [Build](/next/en/build) explains the sequence.

## Why does current CLI output fail with alpha.2?

The preview CLI generates the alpha.3 API. Alpha.2 runtime need not contain those methods. Use the matching alpha.2 generator or a complete staged alpha.3 set. Updating the CLI does not update application dependencies; see [Versions](/next/en/versions).

## Why did findUnique return null?

No matching row is a normal read outcome. Check the key and database target, then handle absence according to application rules. Use `findUniqueOrThrow` when the operation requires a row and handle not-found at the service boundary. A list read with no matches returns an empty list.

## Why does name = null change a row while omitting name does not?

An update form distinguishes intent. Leaving a field unassigned keeps the current column. Assigning null writes SQL NULL, which requires a nullable field. During create, an omitted field can use its supported database default.

## Why does accessing posts throw?

The query did not load that relation through include. An unloaded relation differs from an empty post list returned after explicit loading. Add include when needed or remove the relation from the DTO. A getter never performs a lazy query; see [Relations](/next/en/relations).

## Can include still run several queries?

Yes. Related keys are loaded in batches, and many-to-many adds join-table and target-row reads. This removes a query per parent but does not promise one SQL statement for every include. Batch size, depth and branches affect the count. Included `take` does not guarantee top-N for each parent either.

## Can I return a generated entity as JSON?

A serializer may access every getter, including unloaded relations. Build a DTO from selected scalar fields so the response has an explicit shape and does not need missing data. A projection limits columns in the query itself.

## Can I use Spring @Transactional?

The annotation alone does not prove Volan joins a Spring transaction. Use `db.transaction` and `tx` for related operations. Do not move individual queries from that callback onto another thread. [Web frameworks](/next/en/frameworks) covers lifecycle integration.

## Do coroutines make JDBC nonblocking?

JDBC still occupies a worker. `suspendQuery` suspends the caller and schedules work on a dispatcher. In alpha.3, cancellation requests `Statement.cancel()` and waits for coroutine cleanup; it cannot reverse a commit already underway. Java future cancellation and cleanup occur at different times. See [Async](/next/en/async).

## Can I rerun a failed H2 migration?

Not automatically: DDL may already have committed. Inspect the journal and actual structure, repair the original target state and then complete history. `markApplied` does not run SQL for you. Interrupted push has a separate resolve mechanism; see [Migrations](/next/en/migrations).

## Can I move from SQLite to PostgreSQL unchanged?

Review types, defaults, filters and migration SQL. A shared client scenario can have different storage representations; SQLite does not support Decimal or scalar arrays. Change the provider, dependencies and URL together and test on the target database. [Databases](/next/en/databases) compares providers.

## Is Volan stable for every project?

It is an alpha before 1.0. Suitability depends on operations and provider. Start with a reproducible scenario, review [Limitations](/next/en/limitations), pin versions and test your queries and migrations. The documentation describes current guarantees rather than support for every workload.
