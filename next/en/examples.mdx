Volan 1.0.0. Libraries and build plugins are available from Maven Central.
</Info>

Four independent projects use the 1.0.0 plugin and libraries from Central. They apply committed migrations before using the client. JDK 17+ is required; H2 needs no separate database server.

| Project | Checks |
| --- | --- |
| [Kotlin](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/kotlin-basic) | Transaction, create/read and rollback |
| [Java](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/java-basic) | Java callbacks, Kotlin-generated client, rollback |
| [Spring Boot](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/spring-boot) | Client bean, constructor injection, real context and shutdown |
| [Ktor](https://github.com/thirtyeighttwentysix/volan/tree/v1.0.0/examples/ktor) | Coroutine queries, POST/GET, 400/404 responses and shutdown |

From a checkout of `v1.0.0`, run:

```bash
./gradlew -p examples/kotlin-basic test run
./gradlew -p examples/java-basic test run
./gradlew -p examples/spring-boot test run
./gradlew -p examples/ktor test
```

On PowerShell use `.\gradlew.bat`. `./gradlew -p examples/ktor run` starts the example server on `127.0.0.1:8080`; stop it with Ctrl+C. Console examples print `Saved and read: Ada`.

## Verification

The release workflow builds these projects first against signed staging and then actual Central downloads. `scripts/verify-examples.py --version 1.0.0` performs the same Central checks. `scripts/verify-plugins.py --version 1.0.0` additionally verifies independent Gradle/Maven consumers, caches and deleted-model cleanup. These scripts use disposable copies.

[First query](/next/en/quickstart) explains the files. Detailed query fragments use the User/Post schema: create that schema and matching tables before running them. A focused H2 example does not prove every guarantee of another provider.
