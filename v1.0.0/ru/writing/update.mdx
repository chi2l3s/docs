title: "Изменение записей"
description: "update возвращает строку; updateMany — количество. Поле без присваивания сохраняется."
---

update возвращает строку; updateMany — количество. Поле без присваивания сохраняется.

```kotlin
val created = db.user.create { email = "edit@example.org"; name = "Before" }
val updated = db.user.update {
    where { id eq created.id }
    data { name = "After" }
}
println(updated.name)
```

```java
var created = db.getUser().create(data -> {
    data.setEmail("edit@example.org");
    data.setName("Before");
});
var updated = db.getUser().update(q -> {
    q.where(w -> w.getId().eq(created.getId()));
    q.data(data -> data.setName("After"));
});
System.out.println(updated.getName());
```

```kotlin
val created = db.user.create { email = "clear@example.org"; name = "Alice" }
val cleared = db.user.update {
    where { id eq created.id }
    data { name = null }
}
println(cleared.name)
```

```kotlin
val affected = db.user.updateMany {
    where { name.isNull() }
    data { name = "Unnamed" }
}
println("Updated rows: $affected")
```

Явный null очищает nullable-колонку. Пустой набор данных отклоняется. На PostgreSQL/SQLite/H2 широкий фильтр update может изменить несколько строк и вернуть одну: используй полный ключ. MySQL/MariaDB обновление одной строки блокирует и проверяет совпадения до записи. updateMany не принимает вложенные операции записи.
