---
title: "Создание записей"
description: "create возвращает сохранённую строку. createMany возвращает число вставленных строк."
---

create возвращает сохранённую строку. createMany возвращает число вставленных строк.

```kotlin
val created = db.user.create {
    email = "alice@example.org"
    name = "Alice"
}
println("Created user ${created.id}: ${created.email}")
```

```java
var created = db.getUser().create(data -> {
    data.setEmail("alice@example.org");
    data.setName("Alice");
});
System.out.println("Created user " + created.getId() + ": " + created.getEmail());
```

```kotlin
val inserted = db.user.createMany {
    row { email = "one@example.org" }
    row { email = "two@example.org"; name = "Two" }
}
println("Inserted rows: $inserted")
```

```kotlin
val user = db.user.upsert {
    where { email eq "subscriber@example.org" }
    create { email = "subscriber@example.org"; name = "Subscriber" }
    update { name = "Subscriber" }
}
```

Заполни обязательные поля без default. Неуказанные default-поля заполняет БД. createMany группирует строки по наборам заполненных колонок, разбивает по лимиту параметров и выполняет транзакционно. Возвращаемых сущностей и вложенных операций у createMany нет. Конфликт unique не пропускается автоматически.
