title: "Игнорирование"
description: "ignore оставляет описание в схеме, но убирает его из клиента."
---

ignore оставляет описание в схеме, но убирает его из клиента.

```prisma
model Legacy {
  externalCode String
  payload String?
  @@ignore
}
model Visible {
  id Int @id
  debug String? @ignore
}
```

У `@@ignore` может не быть PK. Генератор пропускает модель, поля с `@ignore` и связи к исключённым моделям. Ignore не удаляет таблицу и не заменяет миграционную политику. Не рассчитывай на ORM-запись обязательной игнорируемой колонки без default: форму таблицы всё равно проверяет БД.
