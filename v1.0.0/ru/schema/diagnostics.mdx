Смотри code, source span и help. За один запуск parser может показать несколько ошибок.

```bash
volan validate --schema schema.volan
```

```text
error[E0104]: expected a field type
  schema.volan:2:9
  email @unique
        ^
help: write name Type, for example email String
```
