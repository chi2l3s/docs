Скалярные массивы поддерживают PostgreSQL и H2. Список связей — другой тип поля.

```prisma
model Preferences {
  id Int @id
  tags String[] @default([])
  scores Int[]
}
```

SQLite, MySQL и MariaDB отклоняют скалярные массивы до генерации. Nullable и вложенные списки недопустимы; nullable-элементы БД не соответствуют сгенерированному non-null типу. Типизированных array-операторов и фильтров списка пока нет. Читай/записывай весь список или используй raw SQL.
