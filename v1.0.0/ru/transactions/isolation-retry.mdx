Повтор выполняет весь блок заново. Включай его только для повторяемых действий.

```kotlin
import io.github.thirtyeighttwentysix.volan.runtime.Isolation
import io.github.thirtyeighttwentysix.volan.runtime.RetryPolicy

val result = db.transaction(
    Isolation.SERIALIZABLE,
    RetryPolicy(attempts = 3, initialDelay = 20, multiplier = 2.0),
) { tx -> tx.user.count() }
```

Isolation: DEFAULT, READ_UNCOMMITTED, READ_COMMITTED, REPEATABLE_READ, SERIALIZABLE. Поддержку уровня определяет JDBC/БД. RetryPolicy.NONE: 1 попытка; DEFAULT: 3; initialDelay=20 мс, multiplier=2. attempts включает первый запуск и должен быть ≥1. Повторяются только retryable VolanTransactionException (deadlock/serialization). Письма и HTTP-вызовы выполняй после успешного commit.
