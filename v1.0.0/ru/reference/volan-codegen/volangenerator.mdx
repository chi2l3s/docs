Контракты типов и членов volan-codegen для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `GeneratedFile`, `VolanGenerationException`, `VolanGenerator`

```kotlin
public class VolanGenerationException(message: String) : VolanException(message)

public class GeneratedFile(public val relativePath: String, public val contents: String)

    override fun toString(): String

public object VolanGenerator

    public fun generate(schema: Schema): List<GeneratedFile>

    public fun generate(schema: Schema, generator: GeneratorConfig): List<GeneratedFile>

    public fun writeTo(schema: Schema, directory: Path): List<Path>
```
