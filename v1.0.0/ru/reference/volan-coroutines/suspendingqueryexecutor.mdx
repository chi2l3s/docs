Контракты типов и членов volan-coroutines для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `SuspendingQueryExecutor`

```kotlin
public class SuspendingQueryExecutor public constructor(
    private val delegate: QueryExecutor,
    private val access: CoroutineAccess = CoroutineAccess.DEFAULT,
)

    public suspend fun <T> findMany(spec: QuerySpec, mapper: RowMapper<T>): List<T>

    public suspend fun <T> findFirst(spec: QuerySpec, mapper: RowMapper<T>): T?

    public suspend fun count(spec: QuerySpec): Long

    public suspend fun exists(spec: QuerySpec): Boolean

    public suspend fun aggregate(spec: AggregateSpec): Map<String, Any?>

    public suspend fun <K> groupBy(spec: GroupSpec, mapper: RowMapper<K>): List<GroupRow<K>>

    public suspend fun <T> create(spec: CreateSpec, mapper: RowMapper<T>): T

    public suspend fun createMany(specs: List<CreateSpec>): Long

    public suspend fun <T> update(spec: UpdateSpec, mapper: RowMapper<T>): T

    public suspend fun updateMany(spec: UpdateSpec): Long

    public suspend fun <T> upsert(spec: UpsertSpec, mapper: RowMapper<T>): T

    public suspend fun <T> delete(spec: DeleteSpec, mapper: RowMapper<T>): T

    public suspend fun deleteMany(spec: DeleteSpec): Long
```
