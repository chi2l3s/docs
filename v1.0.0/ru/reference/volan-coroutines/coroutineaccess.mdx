Контракты типов и членов volan-coroutines для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `CoroutineAccess`, `Companion`, `CoroutineAccessKt`

```kotlin
public class CoroutineAccess public constructor(
    private val dispatcher: CoroutineDispatcher = Dispatchers.IO.limitedParallelism(DEFAULT_PARALLELISM),
)

    public suspend fun <T> execute(block: () -> T): T

    public companion object

        public val DEFAULT: CoroutineAccess

public suspend fun <C, T> C.suspendQuery(access: CoroutineAccess = CoroutineAccess.DEFAULT, block: C.() -> T): T
```
