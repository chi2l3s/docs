Контракты типов и членов volan-core для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `Json`, `Companion`

```kotlin
public class Json private constructor(public val raw: String)

    override fun equals(other: @Nullable Any?): Boolean

    override fun hashCode(): Int

    override fun toString(): String

    public companion object

        public val NULL: Json

        public fun of(raw: String): Json
```
