Контракты типов и членов volan-dialect-mysql для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `MariaDbDialect`, `MySqlDialect`, `MySqlRenderer`

```kotlin
public open class MySqlRenderer(override val id: String) :
    DdlRenderer(
        DialectCapabilities(false, false, false, false, false, true, false, MAXIMUM_PARAMETERS),
    )

    override val timestampWithoutTimeZone: Boolean get()

    override val likeEscape: Char get()

    override val defaultValuesClause: String get()

    override val currentTimestamp: String get()

    override val generatedUuid: String get()

    override fun quote(name: String): String

    override fun initialize(connection: Connection)

    override fun renderForUpdate(select: SqlSelect): SqlStatement

    override fun render(select: SqlSelect): SqlStatement

    override fun Builder.appendOrderBy(terms: List<SqlOrder>)

    override fun Builder.appendLimit(limit: Int?, offset: Int?)

    override fun typeName(type: SqlType): String

    override fun render(type: ColumnType): String

    override fun createTable(create: DdlStatement.CreateTable): String

    override fun autoIncrementType(type: ColumnType): String

    override fun render(ddl: DdlStatement): List<SqlStatement>

    override fun alterColumn(alter: DdlStatement.AlterColumn): List<SqlStatement>

    override fun createIndex(table: String, index: IndexDefinition): String

    override fun jdbcValue(value: Any?): Any?

    override fun sqlState(exception: SQLException): String?

public object MySqlDialect : MySqlRenderer("mysql")

public object MariaDbDialect : MySqlRenderer("mariadb")
```
