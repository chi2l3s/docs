Контракты типов и членов volan-schema для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `Argument`, `ArrayLiteral`, `AstNode`, `Attribute`, `AttributeName`, `BlockAttributeDeclaration`, `BooleanLiteral`, `CommentLine`, `ConfigEntry`, `ConstantReference`, `DatasourceDeclaration`, `Declaration`, `Documented`, `EnumDeclaration`, `EnumMember`, `EnumValueDeclaration`, `Expression`, `FieldDeclaration`, `FunctionCall`, `GeneratorDeclaration`, `Identifier`, `ModelDeclaration`, `ModelMember`, `NumberLiteral`, `SchemaDocument`, `StringLiteral`, `TypeArity`, `TypeReference`
