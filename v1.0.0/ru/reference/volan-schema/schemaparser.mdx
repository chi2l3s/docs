Контракты типов и членов volan-schema для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `ParseResult`, `SchemaParser`, `VolanSchemaException`

```kotlin
public class VolanSchemaException(message: String, public val diagnostics: List<Diagnostic>) : VolanException(message)

public class ParseResult internal constructor(
    public val document: SchemaDocument,
    public val diagnostics: List<Diagnostic>,
    public val source: SourceFile,
)

    public val hasErrors: Boolean

    public val errors: List<Diagnostic>

    public val warnings: List<Diagnostic>

    public fun documentOrThrow(): SchemaDocument

    public fun render(): String

    override fun toString(): String

public object SchemaParser

    public fun parse(source: SourceFile): ParseResult

    public fun parse(name: String, text: String): ParseResult

    public fun parseOrThrow(source: SourceFile): SchemaDocument
```
