JVM entry point CLI. Команды и флаги — в CLI-справочнике.

## Контракты
- [Main](/v1.0.0/ru/reference/volan-cli/main): `MainKt`

Data-классы также имеют value equality, copy и componentN; enum — values/valueOf. Nullable обозначается `?`. Сигнатуры Kotlin с @JvmOverloads имеют Java-overloads; @JvmStatic/@JvmField дают static-доступ. Сериализация или миграция данных из самой сигнатуры не следует.
