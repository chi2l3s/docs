Контракты типов и членов volan-dialect-postgres для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `PostgresDialect`

```kotlin
public object PostgresDialect : DdlRenderer(
    DialectCapabilities(
        returningClause = true,
        insertOnConflict = true,
        caseInsensitiveLike = true,
        distinctOn = true,
        nullsOrdering = true,
        tupleComparison = true,
        arrayColumns = true,
        // The wire protocol counts parameters in a 16-bit field. Volan chunks well below this, but the
        // planner needs the real ceiling to know where a batch has to be split.
        maximumParameters = 65_535,
    ),
)

    override val id: String get()

    override val hasEnumTypes: Boolean get()

    override val generatedUuid: String get()

    override val textParameterType: Int get()

    override fun jdbcValue(value: Any?): Any?

    override fun typeName(type: SqlType): String

    override fun createIndex(table: String, index: IndexDefinition): String

    override fun autoIncrementType(type: ColumnType): String?
```
