Контракты типов и членов volan-ir для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `AnalysisResult`, `SchemaLoader`

```kotlin
public class AnalysisResult internal constructor(
    public val schema: Schema?,
    public val diagnostics: List<Diagnostic>,
    public val source: SourceFile,
)

    public val hasErrors: Boolean

    public val errors: List<Diagnostic>

    public val warnings: List<Diagnostic>

    public fun schemaOrThrow(): Schema

    public fun render(): String

    override fun toString(): String

public object SchemaLoader

    public fun load(source: SourceFile): AnalysisResult

    public fun load(name: String, text: String): AnalysisResult

    public fun loadOrThrow(source: SourceFile): Schema

    public fun analyze(parse: ParseResult): AnalysisResult
```
