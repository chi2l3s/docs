Контракты типов и членов volan-gradle-plugin для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `VolanExtension`, `VolanGenerateTask`, `VolanPlugin`

```kotlin
public abstract class VolanExtension

    public abstract val schemaFile: RegularFileProperty

    public abstract val outputDirectory: DirectoryProperty

public abstract class VolanGenerateTask : DefaultTask()

    public abstract val schemaFile: RegularFileProperty

    public abstract val outputDirectory: DirectoryProperty

    public fun generate()

public class VolanPlugin : Plugin<Project>

    override fun apply(target: Project)
```
