Контракты типов и членов volan-dialect-api для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `SqlAggregate`, `SqlAssignment`, `SqlComparison`, `SqlCondition`, `And`, `Between`, `Compare`, `CompareTuple`, `Exists`, `InList`, `IsNull`, `Not`, `Or`, `TextMatch`, `SqlDelete`, `SqlExpression`, `Call`, `Column`, `Keyword`, `Parameter`, `SqlInsert`, `SqlNulls`, `SqlOrder`, `SqlSelect`, `SqlSelectItem`, `Aggregate`, `Column`, `CountAll`, `SqlStatement`, `SqlTextMatch`, `SqlUpdate`
