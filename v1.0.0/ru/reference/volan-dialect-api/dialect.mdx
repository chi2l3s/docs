Контракты типов и членов volan-dialect-api для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `Dialect`, `DefaultImpls`, `DialectCapabilities`

```kotlin
public data class DialectCapabilities(
    public val returningClause: Boolean,

public interface Dialect

    public val id: String

    public val capabilities: DialectCapabilities

    public val timestampWithoutTimeZone: Boolean get()

    public val textParameterType: Int get()

    public fun renderForUpdate(select: SqlSelect): SqlStatement

    public fun initialize(connection: Connection): Unit

    public fun poolSize(jdbcUrl: String, requested: Int): Int

    public fun connectionMaxLifetime(jdbcUrl: String): @Nullable Long?

    public fun jdbcValue(value: @Nullable Any?): @Nullable Any?

    public fun sqlState(exception: SQLException): @Nullable String?

    public fun render(select: SqlSelect): SqlStatement

    public fun render(insert: SqlInsert): SqlStatement

    public fun render(update: SqlUpdate): SqlStatement

    public fun render(delete: SqlDelete): SqlStatement

    public fun quote(name: String): String
```
