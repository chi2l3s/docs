Контракты типов и членов volan-runtime для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `ConnectOrCreateEntry`, `CreateSpec`, `DeleteSpec`, `NestedWrite`, `ConnectOrCreateRows`, `ConnectRows`, `CreateRows`, `DeleteRows`, `DisconnectRows`, `SetRows`, `UpdateRows`, `NullsOrder`, `OrderTerm`, `Pagination`, `Companion`, `QuerySpec`, `RelationRequest`, `SortDirection`, `UpdateSpec`, `UpsertSpec`
