Контракты типов и членов volan-runtime для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `TableRegistry`

```kotlin
public class TableRegistry(tables: List<TableMetadata>)

    public val models: List<TableMetadata>

    public fun find(model: String): @Nullable TableMetadata?

    public fun require(model: String): TableMetadata

    public fun requireColumn(model: String, field: String): ColumnMetadata

    public fun requireRelation(model: String, field: String): RelationMetadata
```
