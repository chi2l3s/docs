Контракты типов и членов volan-runtime для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `AggregateFunction`, `AggregateScope`, `AggregateSpec`, `AggregateValues`, `Aggregation`, `VolanAggregateNotAskedException`

```kotlin

public class VolanAggregateNotAskedException internal constructor(public val alias: String, description: String) :
    VolanException(
        "this query did not work out $description.\n" +
            "  Ask for it in the `aggregate` block before reading it.",
    )

/** How many rows there are. */
    COUNT,

    /** The total. */
    SUM,

    /** The mean. */
    AVERAGE,

    /** The smallest value. */
    MINIMUM,

    /** The largest value. */
    MAXIMUM,
```
