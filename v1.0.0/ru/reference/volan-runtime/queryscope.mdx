Контракты типов и членов volan-runtime для 1.0.0. Это сигнатуры для справки, не самостоятельная программа. `internal`/`private constructor` недоступен приложению; protected-члены предназначены для подклассов.

**Типы:** `IncludeScope`, `OrderField`, `OrderScope`, `QueryScope`, `SelectScope`

```kotlin
public abstract class OrderScope protected constructor()

    protected fun orderField(column: String): OrderField

    public fun build(): List<OrderTerm>

public class OrderField internal constructor(private val column: String, private val scope: OrderScope)

    public fun asc(): Unit

    public fun desc(): Unit

    public fun ascNullsFirst(): Unit

    public fun ascNullsLast(): Unit

    public fun descNullsFirst(): Unit

    public fun descNullsLast(): Unit

public abstract class SelectScope protected constructor()

    protected fun markSelected(field: String)

    public fun build(): Set<String>

public abstract class IncludeScope protected constructor()

    protected fun includeRelation(relation: String, spec: QuerySpec)

    public fun build(): List<RelationRequest>

public abstract class QueryScope protected constructor(private val model: String)

    public var take: @Nullable Int?

    public var skip: @Nullable Int?

    protected fun recordFilter(scope: FilterScope)

    protected fun recordOrder(scope: OrderScope)

    protected fun recordSelection(columns: List<String>)

    protected fun recordDistinct(columns: List<String>)

    protected fun recordIncludes(scope: IncludeScope)

    protected fun recordCursor(key: Map<String, @Nullable Any?>, inclusive: Boolean)

    public fun build(): QuerySpec
```
