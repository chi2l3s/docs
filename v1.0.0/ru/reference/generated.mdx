Эти контракты сгенерированы 1.0.0 из [User/Post](/v1.0.0/ru/schema). Названия полей, relation scopes и формы записи зависят от схемы. Для другой схемы пересобери клиент.

Kotlin: receiver-lambda. JavaFriendly: Consumer callbacks, getters/setters, builders и CompletableFuture. `Async` есть у каждой операции repository. Scalars required без default обязательны в create; generated/defaulted можно пропустить. Update различает omitted/null. Projection и grouped key имеют is…Selected; relation — is…Loaded. Metadata/mapper классы предназначены для runtime и расширений.
