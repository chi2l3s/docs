| Ситуация | Что проверить |
| --- | --- |
| Сборка успешна, таблицы нет | генерация не создаёт таблицы; примени миграцию |
| После create чтение связи бросает исключение | повторно прочитай с include |
| Java не видит callback | javaFriendly=true и скомпилированные Kotlin-файлы |
| SQLite теряет memory-table | разные соединения, внешний DataSource или закрытие клиента |
| Пустой результат | nullable read или List; OrThrow только при обязательной записи |
| Ошибка future | cause CompletionException/ExecutionException |
| Timeout не мгновенно остановил JDBC | поддержку отмены драйвером и закрытие ресурсов |
| Незавершённая миграция | исходный SQL и исправление структуры вручную, затем markApplied |
| Нет диалекта в classpath | добавь модуль диалекта и JDBC-драйвер |

Подробные контракты: [ошибки](/v1.0.0/ru/errors), [отмена](/v1.0.0/ru/execution/cancellation), [recovery](/v1.0.0/ru/migrations/recovery).
