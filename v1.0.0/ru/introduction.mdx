Volan 1.0.0 — ORM для JVM. Опиши таблицы в `schema.volan`, собери проект и используй сгенерированный клиент.

```kotlin
val users = db.user.findMany {
    where { email endsWith "@example.org" }
    orderBy { id.asc() }
    take = 20
}
```

`db` — открытый клиент; таблицы уже созданы. Значения фильтров передаются в SQL параметрами.

Java 17+ подходит для библиотеки и CLI. Учебный проект использует JDK 25. Поддерживаются PostgreSQL, SQLite, H2, MySQL и MariaDB.

Генерация создаёт код. Таблицы создаются отдельно. Связи загружаются явно через `include`. JDBC занимает рабочий поток и при использовании async или корутин.
