---
title: "Несколько уровней связей"
description: "Опиши каждый уровень include явно. Глубина увеличивает работу и объём результата."
---

Опиши каждый уровень include явно. Глубина увеличивает работу и объём результата.

```kotlin
val posts = db.post.findMany {
    take = 10
    include {
        author {
            include { posts { take = 3 } }
        }
    }
}
```

Загрузка идёт пакетами каждого уровня. Для согласованного снимка нескольких SQL-запросов используй транзакцию с подходящей isolation. Скалярные значения сущности — снимок строки; изменения базы не обновляют уже полученный объект.
