Условия подряд объединяются AND. or, and и not задают группы.

```kotlin
val posts = db.post.findMany {
    where {
        views.between(100, 1000)
        title contains "Volan"
    }
    orderBy { id.asc() }
    take = 20
}
```

```kotlin
val users = db.user.findMany {
    where {
        email.ignoringCase() endsWith "@example.org"
        name.isNotNull()
    }
    orderBy { id.asc() }
    take = 20
}
```

```kotlin
val users = db.user.findMany {
    where {
        email endsWith "@example.org"
        or {
            name eq "Alice"
            name.isNull()
        }
        not { email startsWith "blocked" }
    }
    orderBy { id.asc() }
}
```

```kotlin
val authors = db.user.findMany {
    where { posts { some { views gt 100 } } }
    orderBy { id.asc() }
}
val posts = db.post.findMany {
    where { author { matches { email endsWith "@example.org" } } }
    orderBy { id.asc() }
}
```

```java
var users = db.getUser().findMany(q -> {
    q.where(w -> {
        w.getEmail().endsWith("@example.org");
        w.or(alternative -> {
            alternative.getName().eq("Alice");
            alternative.getName().isNull();
        });
    });
    q.orderBy(o -> o.getId().asc());
    q.setTake(20);
});
```

`eq`, `notEq`, `oneOf`, `notOneOf`, `isNull`, `isNotNull` доступны equality-полям. Ordered добавляет `lt`, `lte`, `gt`, `gte`, `between` с включёнными границами. String добавляет `contains`, `startsWith`, `endsWith`. `ignoringCase` применяется только к eq/notEq и поиску подстроки/краёв; oneOf остаётся sensitive. SQLite case folding ограничен ASCII. Пустые DSL-группы не добавляют условие. [Связи в фильтре](/v1.0.0/ru/querying/relation-filters).
