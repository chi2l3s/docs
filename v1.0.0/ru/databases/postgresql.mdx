Настрой datasource, зависимости и JDBC URL.

```prisma
datasource db {
  provider = "postgresql"
  url = env("DATABASE_URL")
}
```

```kotlin
dependencies {
    implementation(platform("io.github.thirtyeighttwentysix:volan-bom:1.0.0"))
    implementation("io.github.thirtyeighttwentysix:volan-dialect-postgres")
    runtimeOnly("org.postgresql:postgresql:42.7.13")
}
val db = VolanClient.builder().url("jdbc:postgresql://localhost:5432/app").build()
```

PostgreSQL возвращает строки через RETURNING. Поддерживает массивы, native enum и @db. DateTime по умолчанию TIMESTAMP(3), Decimal NUMERIC(65,30), Json JSONB. Для native типов сверяй фактическое хранение. Миграции работают в current schema и транзакции; Volan migration writers используют advisory locks.
