Настрой datasource, зависимости и JDBC URL.

```prisma
datasource db {
  provider = "mariadb"
  url = env("DATABASE_URL")
}
```

```kotlin
dependencies {
    implementation(platform("io.github.thirtyeighttwentysix:volan-bom:1.0.0"))
    implementation("io.github.thirtyeighttwentysix:volan-dialect-mysql")
    runtimeOnly("org.mariadb.jdbc:mariadb-java-client:3.5.10")
}
val db = VolanClient.builder().url("jdbc:mariadb://localhost:3306/app").build()
```

Проверяемый сервер: MariaDB 11.4. Общий модуль dialect-mysql обнаруживает оба провайдера. Используй MariaDB-драйвер и provider=mariadb. Хранение, locks, read-back, ограничения массивов/native типов и recovery совпадают с MySQL; Json использует валидируемый JSON alias MariaDB. DDL commits сразу.
