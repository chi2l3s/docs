---

Проверяет schema и записывает клиент без подключения к БД.

```bash
volan generate --schema db/schema.volan --output build/generated/volan
```

| Флаг | Default / поведение |
| --- | --- |
| --schema | schema.volan |
| --output | generator.output, default build/generated/volan |
