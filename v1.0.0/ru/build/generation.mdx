Сгенерированный код — результат сборки. Исправляй схему, затем генерируй заново.

```bash
volan validate --schema schema.volan
volan generate --schema schema.volan --output build/generated/volan
```

`generate` не подключается к базе. Каталог вывода CLI считается от рабочего каталога; Gradle/Maven задают собственный output и перекрывают значение схемы. `.volan-generated-files` хранит список принадлежащих генератору файлов: удалённые модели и старые пакеты очищаются. Посторонние файлы сохраняются; коллизии, выход за output и символические ссылки внутри него отклоняются. Не редактируй manifest.
