Use isolated embedded databases for database behavior. Use a QueryExecutor test double for query shape.

```kotlin
VolanClient.builder().url("jdbc:sqlite::memory:").build().use { db ->
    // Create the test tables or apply reviewed migrations first.
    val created = db.user.create { email = "test@example.org" }
    check(db.user.findUniqueOrThrow { where { id eq created.id } } == created)
}
```

Give each test a new database. Check defaults, nulls, constraints, rollback and provider SQL on the chosen database. VolanClient(executor) accepts a QueryExecutor implementation; its 13 operations are in the [contract](/v1.0.0/en/reference/volan-runtime). This client has no raw SQL/transactions.
