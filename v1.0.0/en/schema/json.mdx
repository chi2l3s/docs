Json holds JSON text. Your chosen library serializes application objects.

```kotlin
import io.github.thirtyeighttwentysix.volan.Json
val payload = Json.of("""{"theme":"dark"}""")
println(payload.raw)
val jsonNull = Json.NULL
```

```java
import io.github.thirtyeighttwentysix.volan.Json;
var payload = Json.of("{"theme":"dark"}");
System.out.println(payload.getRaw());
```

Json.NULL is JSON null; nullable Json assigned Kotlin/Java null is SQL NULL. Json.of neither creates a DTO nor validates the document structure. JSON-path filters are not generated. Use suitable parameterized raw SQL for PostgreSQL jsonb/H2/MySQL. Database normalization can change whitespace; avoid text equality as semantic JSON comparison.
