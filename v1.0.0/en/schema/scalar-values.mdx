This example uses H2 and a separate Sample model. SQLite supports neither Decimal nor arrays.

```prisma
datasource db {
  provider = "h2"
  url = env("DATABASE_URL")
}
generator client {
  provider = "volan-kotlin"
  package = "org.example.schema.scalars"
  javaFriendly = true
}
enum State {
  NEW @map("new")
  DONE @map("done")
}
model Sample {
  id Int @id
  label String
  state State @default(NEW)
  enabled Boolean @default(true)
  amount Decimal
  ratio Double
  score Float
  total Long
  occurredAt DateTime
  eventDate Date
  eventTime Time
  token Uuid
  data Json
  content Bytes
  scores Int[]
  modifiedAt DateTime? @updatedAt
  note String?
}
```

```kotlin
import io.github.thirtyeighttwentysix.volan.Json
import org.example.schema.scalars.State
import java.math.BigDecimal
import java.time.Instant
import java.time.LocalDate
import java.time.LocalTime
import java.util.UUID

val created = db.sample.create {
    id = 1
    label = "Measurement"
    amount = BigDecimal("12.50")
    ratio = 0.5
    score = 1.25f
    total = 5_000_000_000L
    occurredAt = Instant.parse("2026-01-01T00:00:00Z")
    eventDate = LocalDate.of(2026, 1, 1)
    eventTime = LocalTime.of(12, 30)
    token = UUID.fromString("85a42b5c-b3c0-4e40-bbed-88c40428f1ba")
    data = Json.of("""{"source":"sensor"}""")
    content = byteArrayOf(1, 2, 3)
    scores = listOf(10, 20)
}
check(created.state == State.NEW)
check(created.enabled)
check(created.note == null)
val updated = db.sample.update {
    where { id eq created.id }
    data { state = State.DONE; note = "Checked" }
}
```

Construct BigDecimal from a string to avoid carrying Double rounding errors. Long literals use L, Float f. UUID maps to the JVM UUID type. Bytes use ByteArray: compare contents with contentEquals. Enum mapping stores "new"/"done" while application code uses State. Runtime fills modifiedAt from its clock even though the column is nullable. Json.of stores text without validating JSON. Read/write scores as an entire list. [Round-trip check](https://github.com/chi2l3s/docs/blob/main/examples/query-guide-1.0.0/src/test/kotlin/org/example/ScalarGuideExamplesTest.kt).
