---
title: "Relations in the schema"
description: "Declare both ends of a relation. The foreign key belongs to the single-value side."
---

Declare both ends of a relation. The foreign key belongs to the single-value side.

```prisma
model User {
  id Int @id @default(autoincrement())
  email String @unique
  name String?
  posts Post[]
}

model Post {
  id Int @id @default(autoincrement())
  title String
  views Int @default(0)
  authorId Int
  author User @relation(fields: [authorId], references: [id], onDelete: Cascade)
}
```

```prisma
model Account {
  id Int @id @default(autoincrement())
  profile Profile?
}

model Profile {
  id Int @id @default(autoincrement())
  accountId Int @unique
  account Account @relation(fields: [accountId], references: [id], onDelete: Cascade)
}
```

```prisma
model Article {
  id Int @id @default(autoincrement())
  tags Tag[]
}

model Tag {
  id Int @id @default(autoincrement())
  name String @unique
  articles Article[]
}
```

Exactly one side declares fields/references; lists align and types match. References target PK/unique fields. One-to-one needs a unique FK. Name multiple relations between the same models. Many-to-many creates a join table named for the relation.
