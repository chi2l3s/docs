Volan 1.0.0 is a JVM ORM. Describe tables in `schema.volan`, build the project and use the generated client.

```kotlin
val users = db.user.findMany {
    where { email endsWith "@example.org" }
    orderBy { id.asc() }
    take = 20
}
```

`db` is an open client; tables already exist. Filter values become SQL parameters.

The library and CLI require Java 17+. The tutorial uses JDK 25. PostgreSQL, SQLite, H2, MySQL and MariaDB are supported.

Generation creates code. Create tables separately. Load relations explicitly with `include`. JDBC occupies a worker even through async or coroutine access.
