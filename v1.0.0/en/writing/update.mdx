---
title: "Updating records"
description: "update returns a row; updateMany returns a count. Unassigned fields stay unchanged."
---

update returns a row; updateMany returns a count. Unassigned fields stay unchanged.

```kotlin
val created = db.user.create { email = "edit@example.org"; name = "Before" }
val updated = db.user.update {
    where { id eq created.id }
    data { name = "After" }
}
println(updated.name)
```

```java
var created = db.getUser().create(data -> {
    data.setEmail("edit@example.org");
    data.setName("Before");
});
var updated = db.getUser().update(q -> {
    q.where(w -> w.getId().eq(created.getId()));
    q.data(data -> data.setName("After"));
});
System.out.println(updated.getName());
```

```kotlin
val created = db.user.create { email = "clear@example.org"; name = "Alice" }
val cleared = db.user.update {
    where { id eq created.id }
    data { name = null }
}
println(cleared.name)
```

```kotlin
val affected = db.user.updateMany {
    where { name.isNull() }
    data { name = "Unnamed" }
}
println("Updated rows: $affected")
```

Explicit null clears a nullable column. Empty payloads are refused. PostgreSQL/SQLite/H2 update can affect multiple rows and return one: use a full key. MySQL/MariaDB lock and check matches before a single-row write. updateMany rejects nested writes.
