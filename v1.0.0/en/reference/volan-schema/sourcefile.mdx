Type/member contracts of volan-schema for 1.0.0. These signatures are reference material, not a standalone program. Internal/private constructors are not callable by applications; protected members serve subclasses.

**Types:** `SourceFile`, `SourcePosition`, `SourceSpan`

```kotlin
public class SourceFile(public val name: String, public val text: String)

    public val lineCount: Int

    public fun positionOf(offset: Int): SourcePosition

    public fun lineText(line: Int): String

    override fun toString(): String

public data class SourcePosition(
    public val line: Int,
    public val column: Int,
    public val offset: Int,
)

    override fun toString(): String

public data class SourceSpan(public val start: Int, public val end: Int)

    public val length: Int

    public fun union(other: SourceSpan): SourceSpan

    override fun toString(): String
```
