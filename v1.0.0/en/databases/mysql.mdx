Configure datasource, dependencies and the JDBC URL.

```prisma
datasource db {
  provider = "mysql"
  url = env("DATABASE_URL")
}
```

```kotlin
dependencies {
    implementation(platform("io.github.thirtyeighttwentysix:volan-bom:1.0.0"))
    implementation("io.github.thirtyeighttwentysix:volan-dialect-mysql")
    runtimeOnly("com.mysql:mysql-connector-j:26.7.0")
}
val db = VolanClient.builder().url("jdbc:mysql://localhost:3306/app").build()
```

Verified server: MySQL 8.4, InnoDB, utf8mb4_bin. Borrowed connections use UTC, ANSI_QUOTES, NO_BACKSLASH_ESCAPES and STRICT_TRANS_TABLES. String/enums use VARCHAR(191), UUID CHAR(36), Bytes LONGBLOB, Boolean TINYINT(1), Decimal DECIMAL(65,30), DateTime DATETIME(6), Time TIME(6), native JSON. Supply UUID primary keys in application code. Create reads the generated key then the row in one transaction; update/delete first lock FOR UPDATE and verify a single match. Distinct requires exact projection. DDL commits immediately; migration/push use named session locks.
