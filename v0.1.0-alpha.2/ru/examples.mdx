<Info>
Volan 0.1.0-alpha.2. Опубликованные библиотеки для PostgreSQL и SQLite.
</Info>

[Первый запрос](/v0.1.0-alpha.2/ru/quickstart) — полное приложение alpha.2 с точками входа Kotlin и Java, закреплённым wrapper и генератором из Central той же версии. SQLite-база существует только во время запуска: каждая точка входа начинает без строк.

## Скачать и запустить

[Проект примера](https://github.com/chi2l3s/docs/tree/main/examples/first-query). В его каталоге выполни:

```bash
./gradlew runKotlinExample runJavaExample
```

В Windows используй `.\gradlew.bat`; нужен JDK 25. Обе задачи печатают Alice и `Users: 1`. Результат генерации остаётся в build; пример не меняет базу развёрнутого приложения.

## Существующий сервис

В [Фреймворках](/v0.1.0-alpha.2/ru/frameworks) показаны Spring bean и жизненный цикл Ktor. Примени миграции до обслуживания запросов. В отличие от временного первого примера, route работает с постоянной базой.

## Проверка релиза

[Release smoke из тега alpha.2](https://github.com/thirtyeighttwentysix/volan/tree/v0.1.0-alpha.2/release-smoke) генерирует, компилирует и выполняет независимые consumers из Maven-артефактов. Он покрывает PostgreSQL и SQLite; серверным проверкам нужна тестовая БД.

## Развить пример

Добавь связь Post из [Схемы](/v0.1.0-alpha.2/ru/schema), заново сгенерируй клиент и примени миграцию. Разбери чтение связей через include и объедини связанные записи транзакцией, когда операция должна выполниться целиком. Успешный SQLite-пример не заменяет тестирование на СУБД приложения.
