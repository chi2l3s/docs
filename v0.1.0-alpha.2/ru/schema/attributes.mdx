Атрибут уточняет смысл поля или модели: где ключ, какое значение подставлять при вставке, как называется колонка и как связаны таблицы. `@` относится к полю, `@@` — ко всей модели. Эти настройки влияют на клиент и описание базы, поэтому после изменения проверь обе части.

## Где писать атрибут

Атрибуты поля должны быть на той же строке, что его имя и тип. Атрибуты модели пишутся отдельной строкой внутри блока:

```prisma
model Article {
  id Int @id @default(autoincrement())
  title String
  createdAt DateTime @default(now()) @map("created_at")
  updatedAt DateTime @updatedAt @map("updated_at")

  @@index([createdAt])
  @@map("articles")
}
```

Здесь SQL-имена отличаются от имён свойств, а индекс задан для времени создания. Генерация обновит Kotlin-код, но индекс и default появятся в базе только после применения изменения структуры.

## Ключи и ограничения

| Атрибут | Задача | На что обратить внимание |
| --- | --- | --- |
| `@id` | Одно поле первичного ключа | Обязательное скалярное значение |
| `@@id([a, b])` | Составной первичный ключ | Для одной строки нужны все части |
| `@unique` | Уникальность одной колонки | Правила сравнения определяет база |
| `@@unique([a, b])` | Уникальность комбинации | Не заменяет первичный ключ модели |
| `@@index([a, b])` | Индекс колонок | Не гарантирует уникальность |

Ключи разобраны с примерами в [моделях](/v0.1.0-alpha.2/ru/schema/models). `findUnique` использует обычное чтение первой строки и не проверяет уникальность условия. Ограничение базы и корректный фильтр нужны даже при таком имени метода.

## `@default(...)`

Default используется при вставке, когда приложение не передало значение. Допустимы совместимые литералы, значение enum, `autoincrement()`, `now()` и `uuid()`.

`autoincrement()` применяют к подходящему целочисленному ключу. `now()` задаёт текущее время для совместимого временного поля, `uuid()` — значение для `Uuid` или `String`. Конкретное SQL-выражение и поддержка зависят от диалекта: сверяй [особенности СУБД](/v0.1.0-alpha.2/ru/databases).

Default не означает «заменять переданное значение» и не является валидацией. При `views = 15` default `0` не применяется. При явном null база применяет свои ограничения nullable, а не автоматически возвращается к default.

## `@updatedAt`

Этот атрибут ставится на обязательное поле `DateTime`. Volan подставляет timestamp при создании и обновлении через типизированный API. На обновлении поле управляется runtime, даже если payload пытается передать другое значение.

Это не триггер базы. Ручной SQL через `rawExecute`, внешний скрипт и другое приложение не получают такого поведения автоматически. Если все источники записи должны обновлять timestamp одинаково, продумай правило на стороне БД и проверь совместимость клиента.

## Mapping и нативный тип

`@map("column")` меняет SQL-имя поля, `@@map("table")` — SQL-имя модели. В коде сохраняются имена схемы. На enum `@map` у значения меняет хранимую строку, а `@@map` относится к имени enum в базе.

Нативный тип задаётся через `@db`, например `@db.VarChar(320)` для PostgreSQL. Он уточняет хранение, не превращая Kotlin `String` в другой класс. В alpha.2 нативные типы @db доступны для PostgreSQL. Не переноси нативную аннотацию между провайдерами без проверки.

## Связи и исключение из клиента

`@relation(fields: [...], references: [...], onDelete: ..., onUpdate: ...)` описывает внешний ключ и действия при изменении связанной записи. Это правила таблиц, а не скрытые запросы при чтении свойства. Формы связей и referential actions описаны [отдельно](/v0.1.0-alpha.2/ru/schema/relations).

`@ignore` исключает поле из сгенерированного клиента, `@@ignore` — модель. Если исключённая колонка обязательна и не имеет default в реальной таблице, вставки могут оказаться невозможными: клиент не передаёт её значение. Не используй ignore как замену безопасному DTO.

`@@fulltext` не даёт типизированного поискового API и не является переносимым способом включить полнотекстовый поиск. Проверь возможности диалекта и явный SQL для своей базы.
