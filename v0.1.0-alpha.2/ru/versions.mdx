## Обновление вместе

Runtime, диалект, библиотека миграций и codegen должны иметь версию `0.1.0-alpha.2`. BOM выравнивает библиотеки Volan, но отдельному генератору сборки тоже нужна соответствующая версия. После обновления заново генерируй и компилируй клиент.

Alpha.2 добавляет SQLite и исправляет сохранение defaults/порядка при bulk insert и сопоставление JDBC-ключей связей. Обновление с alpha.1 не переносит данные PostgreSQL в SQLite автоматически. Осознанно выбери provider, схему, зависимости и URL, затем проверь SQL миграций на целевой СУБД.

## Отдельные релизы CLI

Переносимый `cli-v0.1.0-alpha.3-preview.1` — отдельная программа, генератор которой рассчитан на alpha.3. Он не обновляет библиотеки и не заменяет codegen alpha.2. CLI из тега alpha.2 предоставляет pull/push базы и собирается из исходников.

Версионированный URL остаётся на своём релизе. Старые ссылки без версии перенаправляются на alpha.2. Состав опубликованной поставки описан в [release notes](https://github.com/thirtyeighttwentysix/volan/releases/tag/v0.1.0-alpha.2); примеры разработки используют подготовленные артефакты.
