## Upgrade together

Pin runtime, dialect, migration library and codegen to `0.1.0-alpha.2`. The BOM aligns Volan libraries, but a build-only generator still needs the matching version. Regenerate and compile after upgrading.

Alpha.2 adds SQLite and fixes bulk insert defaults/order and JDBC relation-key matching. Moving from alpha.1 does not automatically move PostgreSQL data to SQLite: choose provider, schema, dependencies and URL intentionally, then test migration SQL against the target.

## Separate CLI releases

The portable `cli-v0.1.0-alpha.3-preview.1` is a separate executable whose generator targets alpha.3. It does not update libraries and cannot replace alpha.2 codegen. The alpha.2 tagged CLI provides database pull/push and can be built from source.

An older documentation URL stays on its release. Old unversioned links redirect to alpha.2. [Release notes](https://github.com/thirtyeighttwentysix/volan/releases/tag/v0.1.0-alpha.2) describe the published package; development examples use staged artifacts.
