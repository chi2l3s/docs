Запусти независимые consumers для проверки генерации вместе с runtime.

| Пример | Проверки | Требования |
|---|---|---|
| [Первый запрос](/ru/quickstart) | Alpha.2 Kotlin/Java, явный DDL SQLite, insert/read, закрытие | Java 17+, Gradle |
| [plugin-smoke/gradle](https://github.com/thirtyeighttwentysix/volan/tree/main/plugin-smoke/gradle) | Alpha.3 plugin, Kotlin/Java H2 CRUD, корутины, метрики | Staged artifacts |
| [plugin-smoke/maven](https://github.com/thirtyeighttwentysix/volan/tree/main/plugin-smoke/maven) | Alpha.3 generation и Java H2 CRUD | Maven 3.9+, staged artifacts |
| [release-smoke](https://github.com/thirtyeighttwentysix/volan/tree/main/release-smoke) | Независимые artifacts, SQLite/H2 и серверные consumers | Docker для серверных тестов |

Схема H2 plugin consumer:

```prisma
datasource db {
  provider = "h2"
  url = env("UNSET_PLUGIN_SMOKE_URL")
}
generator client {
  provider = "volan-kotlin"
  package = "example.generated"
  javaFriendly = true
}
model User {
  id Int @id @default(autoincrement())
  name String
}
```

Тесты Kotlin/Java явно создают User до записи и закрывают клиент. [Сборка](/ru/build) содержит полную конфигурацию Gradle/Maven.

После подготовки alpha.3 из корня репозитория:

```bash
python scripts/verify-plugins.py --version 0.1.0-alpha.3 --repository build/release-repository
./gradlew -p release-smoke test "-PvolanVersion=0.1.0-alpha.2" --tests smoke.PublishedSqliteTest
```

Verifier копирует consumers перед изменением схем, проверяет обычную сборку, configuration cache, удаление source/bytecode модели и восстановление из Gradle build cache. Если Maven отсутствует в PATH, передай `--maven /path/to/mvn`. SQLite release test не требует Docker; отдельный тест не означает проверку всей серверной suite.

Новые snippets первого запроса скомпилированы и выполнены с Central alpha.2. Полные проекты фреймворков и их CI smoke остаются работой M11; [Фреймворки](/ru/frameworks) описывают интеграцию.
