## Init создаёт приложение?

Только schema.volan. Настрой [Gradle/Maven](/ru/build), сгенерируй клиент и явно создай таблицы.

## Почему код preview CLI не собирается с alpha.2?

Текущий preview рассчитан на alpha.3. Используй [генератор alpha.2](/ru/quickstart) либо полный совпадающий staged alpha.3 набор.

## Сборка создаёт таблицы или миграции?

Нет. Генерация не подключается к БД. Выполняй [синхронизацию](/ru/sync) или проверенные операции [Migrator](/ru/migrations) отдельно.

## Java может работать с клиентом?

Да: включи javaFriendly = true и сначала скомпилируй generated Kotlin. Используй getters, setters и Consumer callbacks; futures переносят блокирующий JDBC.

## SuspendQuery — reactive API?

Нет. Он переносит JDBC на ограниченный dispatcher. [Отмена](/ru/async) вызывает Statement.cancel и ждёт cleanup корутины; завершённый commit она не отменяет.

## Include делает запрос на каждого пользователя?

Связанные ключи загружаются batches. [Связи](/ru/relations) объясняют chunks, many-to-many и лимиты пагинации.

## Можно сериализовать entity напрямую?

Serializer может прочитать незагруженный getter и получить исключение. Создай DTO из выбранных полей.

## Можно повторить прерванную миграцию H2?

Не автоматически. Проверь и исправь committed DDL, затем отметь исходную миграцию applied. Для partial push используй resolve после восстановления исходной цели.

## Volan готов к 1.0?

Проект находится до 1.0. API и ограничения СУБД описаны явно; примеры M11 и задачи M12 ещё не все завершены.
