Сгенерированный код обращается к API runtime. Поэтому версия генератора важна не меньше версии библиотеки в dependencies: новый генератор может создать вызовы, которых нет в старом runtime. Обновляй их согласованно и повторяй генерацию после изменения версии.

Доступность библиотек проверена по Maven Central 5 октября 2026 года. Последняя опубликованная библиотечная версия — `0.1.0-alpha.2`; CLI preview и исходники alpha.3 являются отдельными поставками.

| Версия | Поставка | Возможности |
|---|---|---|
| 0.1.0-alpha.1 | Central, GitHub library release | PostgreSQL |
| 0.1.0-alpha.2 | Последний library release в Central | PostgreSQL и SQLite |
| cli-v0.1.0-alpha.3-preview.1 | CLI release на GitHub | Отдельный executable preview |
| 0.1.0-alpha.3-SNAPSHOT | Версия исходников main | Development libraries/plugins |
| 0.1.0-alpha.3 local candidate | Локальный staged Maven repository | Проверка без публикации в Central |

[Central metadata](https://repo.maven.apache.org/maven2/io/github/thirtyeighttwentysix/volan-runtime/maven-metadata.xml), [alpha.2 release notes](https://github.com/thirtyeighttwentysix/volan/releases/tag/v0.1.0-alpha.2), [CLI release](https://github.com/thirtyeighttwentysix/volan/releases/tag/cli-v0.1.0-alpha.3-preview.1).

CLI preview генерирует код для alpha.3. Не используй его с runtime alpha.2. Прямая генерация alpha.2 показана на странице [Первый запрос](/ru/quickstart); alpha.3 generator/plugins требуют [staging](/ru/build).

Установка или обновление CLI не меняет зависимости приложения. Library releases alpha.1/alpha.2 не содержат установочных CLI-архивов. На момент проверки библиотечная alpha.3 не опубликована.

Перед обновлением прочитай release notes, повтори генерацию, скомпилируй Kotlin и Java consumers, проверь целевую БД и SQL миграций. Alpha API может меняться.

## Как распознать несовпадение

Если сгенерированные файлы ссылаются на отсутствующий метод или класс, сначала сравни версии codegen и runtime. Удаление конкретной строки из generated code лишь скрывает проблему до следующей генерации. Аналогично, plugin alpha.3 не становится совместимым с alpha.2 из-за того, что Gradle смог загрузить его JAR.

BOM управляет версиями модулей Volan в зависимости приложения. Он не обновляет системный CLI, не задаёт plugin version и не переписывает существующий generated output. Это отдельные части конфигурации, которые нужно проверить.

## Обновление в приложении

Сохрани изменения схемы и migrations, обнови совпадающий набор библиотек и генератор, затем заново сгенерируй и скомпилируй клиент. Проверь Kotlin и Java точки использования, если проект использует оба языка. Запусти операции на целевой СУБД и отдельно проверь переход структуры от предыдущей версии.

Локально подготовленная alpha.3 позволяет проверить новые возможности до публикации. Её repository URI должен быть доступен всем нужным этапам сборки. Не описывай такой кандидат как артефакт из Central и не смешивай его с alpha.2.
