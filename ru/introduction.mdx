Volan генерирует Kotlin-клиент с Java API из файла `schema.volan`. Клиент выполняет запросы через JDBC; таблицы нужно создать до первого обращения к репозиторию.

## Выбор версии

| Поставка | Доступная версия | Возможности |
|---|---|---|
| Библиотеки Maven Central | `0.1.0-alpha.2` | PostgreSQL и SQLite |
| CLI на GitHub | `cli-v0.1.0-alpha.3-preview.1` | Отдельный preview, генератор для alpha.3 |
| Исходники main | `0.1.0-alpha.3-SNAPSHOT` | H2, MySQL, MariaDB, build plugins, корутины и метрики |

Библиотеки и плагины alpha.3 ещё не опубликованы в Central. Версии генератора и runtime должны совпадать. Preview CLI не подходит как генератор для alpha.2.

Начни с [установки](/ru/installation), затем выполни [первый запрос](/ru/quickstart). Плагины из исходников описаны на странице [Сборка](/ru/build). Перед выбором типов и процедуры миграций прочитай [СУБД](/ru/databases).

## Гарантии runtime

Клиент использует сгенерированный маппинг, явную загрузку связей и параметры запросов. Lazy proxies и автоматических tenant-фильтров нет. JDBC остаётся блокирующим при работе через корутины и futures. API может меняться до 1.0.

[Версии](/ru/versions) описывают границы релизов, [Ограничения](/ru/limitations) — неподдерживаемые случаи. M0–M10 обозначают этапы, а не модули. В M11 ещё остаются примеры фреймворков и их проверки CI.
