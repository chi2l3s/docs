This is the archived `0.1.0-alpha.1` documentation. Its supported database is PostgreSQL. Keep generator, runtime, dialect and migration library on alpha.1 for an existing application.

## Upgrade to alpha.2

[Alpha.2](/v0.1.0-alpha.2/en/introduction) adds SQLite and fixes heterogeneous bulk insert defaults/order and JDBC relation-key matching. Update the BOM and codegen together, regenerate and compile. Test reads, nested writes and migrations against the actual deployment database.

An upgrade does not move rows to another database or create tables. Keep PostgreSQL when only updating the libraries; choose a different provider as a separate change with its own migration plan.
